### 📂 Proyectos Destacados

- 📁 **[Sistema de Gestión de Ficheros y Persistencia (Java I/O)](https://github.com/hugomsedeno/java-gestion-ficheros-persistencia)**
  Aplicación en Java para la administración programática de directorios, borrado recursivo de árboles de carpetas y persistencia secuencial de registros con `BufferedReader` y `BufferedWriter`.

- ⚙️ **[Gestor de Procesos del Sistema y Subprocesos (Java PSP)](https://github.com/hugomsedeno/java-gestor-procesos-sistema)**
  Conjunto de utilidades en Java para auditoría de procesos activos y núcleos de CPU con `ProcessHandle`, ejecución multiplataforma de subprocesos con `ProcessBuilder` y captura de argumentos CLI.
